# Audio VAE acceptance contract, PR #10253

- Reference: released full MiniMax-H3 Ref2VA Audio VAE and upstream `27db0acbbdb8ca1580215af18934409825b48564`; candidate source is the clean Git head named in each window's `run-identity.txt`. Hardware: one free Ascend 910B4-1, verified Ascend nightly CANN 9.3.0 with host driver 25.5.0. Fixed FP32 checkpoints and no SDK patches. Short mono 24 kHz (resample + channel duplication) and long stereo 32 kHz (distinct channels, direct path).
- Encoder `L1`: compare raw little-endian FP32 bytes (not `.pt` serialization). Main before/main after, head omitted configuration, head opt-in installed, and separate encode-only instances must match for each input. Require two full-model encodes per arm, identical tensor shape and frame count, positive size and finite samples. Keep files, MD5 and SHA256.
- Decoder default `L1`: same synchronized off waveform bytes in stock main before/after, head default, and head opt-in with both wrappers bypassed. Same shape/rate across all arms; no published speedup for the default.
- Decoder opt-in `L2` only, not lossless: predeclare SNR >= 60 dB and max absolute FP32 waveform error <= 0.002 versus same-window stock, zero sample shift/unchanged sample count and channels, finite waveform, and raw hash repeatability across five formal measurements. These are conservative component regression guardrails (60 dB means noise RMS at most 0.1% of reference RMS); they are not a listening test or a general quality claim. Preserve all waveform files if an arm fails.
- Applicability/engagement: per-measurement counts for FIR executed, FIR fallbacks and stage polyphase. Off must execute neither; each isolated arm executes only its selected path. Count warmups separately; exclude them and output dumping from latency statistics. Report individual samples, median, mean, variability, and peak allocated and reserved memory. No throughput, video/MP4, or end-to-end/HTTP claim for this component harness.
- Preserve the previously committed FIR and inventory tests unchanged, compare their blobs before and after; accept the relevant original tests and additional regression cases only if pytest passes. Note any CI suites or device generations not exercised.
